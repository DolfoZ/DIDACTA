Rueda de genio

El código numérico CIRCE, comúnmente conocido como "rueda mágica", se está

utilizado ampliamente en Vietnam por unidades del ejército estadounidense. El código era originalmente

Diseñado y producido por la Fuerza Aérea de EE. UU. para uso de la Fuerza Aérea y el Ejército.

unidades involucradas en operaciones aire-tierra para codificar números para transmisión

a través de redes de radio no seguras. Los comandantes del ejército quedaron rápidamente impresionados con su

rapidez y simplicidad de operación. Esto condujo a una rápida expansión del sistema a

Uso terrestre del ejército. La Fuerza Aérea creía que una alta densidad y uso de unidades

comprometer rápidamente el sistema y, como resultado, el sistema estratégico del ejército de EE. UU.

El Comando de Comunicaciones desarrolló un sistema similar para uso del Ejército.

El sistema actual se utiliza para cifrar los tiempos TOT (tiempo objetivo),

coordenadas, altitudes, frecuencias de radio y otra información numérica en

áreas donde la amenaza de que el enemigo rompa el código es mínima. Su uso
