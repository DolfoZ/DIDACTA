Partido balístico

Ballistic Match simplifica enormemente las simulaciones de trayectoria generalizadas. El análisis

ejecuta una serie de trayectorias de 4 o 6DOF entre 0 y 80 grados de elevación y guarda

puntos de impacto, condiciones de impacto, ángulo de caída y rangos y altitudes de culminación.

Ballistic Match itera automáticamente la elevación del cuadrante del arma, salvando al diseñador

iteraciones tediosas para hacer que una bala alcance un objetivo a una distancia determinada.

Las elevaciones de cuadrante requeridas y los parámetros clave de trayectoria para cada rango inter-

val para referencia rápida. Ballistic Match se puede utilizar solo para mostrar el máximo

información de elevación de rango y cuadrante, o se puede utilizar junto con el

módulo de trayectoria para generar condiciones iniciales. Este módulo también puede usar personalizado

atmósferas, variando la altitud del arma y el objetivo, y calcula automáticamente

el alcance máximo del proyectil.
