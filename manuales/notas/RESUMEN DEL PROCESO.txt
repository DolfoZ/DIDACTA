EVALUACIÓN DE CUMPLIMIENTO CON LOS TEXTOS
FM 6-40 (Cannon Gunnery): El texto indica explícitamente que "los datos para elevaciones no disparadas se determinan mediante interpolación". Por lo tanto, el uso de interpolación cumple estrictamente con el requerimiento doctrinario. La interpolación lineal simple es el estándar para el cálculo manual y gráfico en el Centro de Dirección de Tiro (FDC).

Modelado Físico (FM 6-40): El manual estipula que la resistencia aerodinámica (drag) no es lineal, sino que es proporcional al cuadrado de la velocidad y varía de manera drástica al acercarse a la velocidad del sonido. Una interpolación puramente lineal introduce un margen de error respecto a la curvatura de la trayectoria real.

Ecosistema de Cálculo (Math Pac): El manual detalla capacidades avanzadas como integración numérica y resolución de ecuaciones. En computadores de tiro de alta fidelidad, la mejor opción es emplear métodos de interpolación no lineales (como trazadores polinómicos o splines cúbicos) para ajustarse a la curvatura física de las trayectorias tabuladas.

El error del método: Al aplicar una interpolación lineal entre los puntos de la tabla (por ejemplo, entre 1200 m y 1300 m), estamos asumiendo falsamente que el comportamiento de la bala en ese tramo es una línea recta perfecta. La precisión mide la repetibilidad y consistencia del sistema; es decir, la capacidad de dar el mismo resultado una y otra vez bajo las mismas condiciones.

def interpolar_lineal(x: float, x0: float, x1: float, y0: float, y1: float) -> float:
    """Aplica la fórmula estándar de interpolación lineal."""
    return y0 + (x - x0) * (y1 - y0) / (x1 - x0)

def calcular_datos_tiro(calibre: str, distancia: float) -> Optional[Dict[str, Any]]:
    """
    Evalúa el algoritmo balístico, determina la carga óptima y calcula 
    Elevación, Tiempo de Vuelo y Deriva.
    """

        print(f"[ERROR] Calibre '{calibre}' no soportado.")
        return None
        
    cargas_disponibles = TABLAS_BALISTICAS[calibre]
    carga_seleccionada = None
    datos_carga = None

    for nombre_carga, tabla in cargas_disponibles.items():
        distancias = sorted(list(tabla.keys()))
        min_dist = distancias[0]
        max_dist = distancias[-1]

            "tf": tf,
            "df": df,
            "exacto": True
        }

        if distancias_tabla[i] < distancia < distancias_tabla[i+1]:

SOLUCIÓN COMPLETA: ALGORITMO DE SIMULACIÓN BALÍSTICA (Paso a Paso)
Este código implementa la integración numérica para resolver la trayectoria exacta y utiliza un bucle de búsqueda para encontrar el ángulo de elevación (QE) perfecto para impactar a la distancia deseada.

Python
import math
from typing import Dict, Any, Tuple

class SimuladorBalisticoAvanzado:
    def __init__(self):
        # Constantes Físicas
        self.g = 9.80665  # Gravedad m/s^2
        self.rho = 1.225  # Densidad del aire estándar kg/m^3
        
        # Datos técnicos del Obús 105mm M102 (Proyectil HE M1)
        self.masa = 14.97  # kg
        self.calibre = 0.105  # metros
        self.area = math.pi * (self.calibre / 2) ** 2  # Área frontal
        self.cd = 0.25  # Coeficiente de arrastre aproximado para proyectil ojival
        
        # Velocidades iniciales aproximadas por carga (m/s)
        self.velocidades_carga = {
            "Carga 1": 200.0,
            "Carga 2": 250.0,
            "Carga 3": 300.0
        }

    def simular_vuelo(self, v0: float, theta_mils: float, dt: float = 0.005) -> Tuple[float, float, float]:
        """
        Simula la trayectoria completa paso a paso en el tiempo (Método de Euler).
        Retorna: (Distancia final alcanzada, Tiempo de vuelo, Altura máxima)
        """
        # Convertir mils a radianes (6400 mils = 2*pi rad)
        theta_rad = (theta_mils * 2 * math.pi) / 6400.0
        
        # Condiciones iniciales
        x, y = 0.0, 0.0
        vx = v0 * math.cos(theta_rad)
        vy = v0 * math.sin(theta_rad)
        
        t = 0.0
        y_max = 0.0
        
        # Factor de arrastre constante para optimizar CPU
        factor_drag = (self.rho * self.cd * self.area) / (2 * self.masa)
        
        while y >= 0:
            v = math.hypot(vx, vy)
            
            # Cálculo de aceleraciones (Gravedad + Arrastre)
            ax = -factor_drag * v * vx
            ay = -self.g - (factor_drag * v * vy)
            
            # Integración numérica (Actualización de posición y velocidad)
            x += vx * dt + 0.5 * ax * (dt**2)
            y += vy * dt + 0.5 * ay * (dt**2)
            
            vx += ax * dt
            vy += ay * dt
            
            t += dt
            if y > y_max:
                y_max = y
                
        return x, t, y_max

    def calcular_solucion_tiro(self, distancia_objetivo: float, tolerancia: float = 1.0) -> Dict[str, Any]:
        """
        Encuentra la carga y el ángulo QE exactos mediante aproximaciones sucesivas.
        """
        print(f"\n[SISTEMA] Iniciando cálculo de trayectoria para: {distancia_objetivo} metros.")
        
        carga_optima = None
        v0_optima = 0.0
        
        # 1. Selección de Carga (fuerza bruta sobre capacidades máximas a 45 grados o 800 mils)
        for carga, v0 in self.velocidades_carga.items():
            dist_max, _, _ = self.simular_vuelo(v0, 800.0) # 800 mils = 45 grados
            if dist_max >= distancia_objetivo:
                carga_optima = carga
                v0_optima = v0
                break
                
        if not carga_optima:
            return {"error": "Distancia fuera del alcance máximo de todas las cargas."}
            
        print(f"[SISTEMA] Carga seleccionada: {carga_optima} (V0 = {v0_optima} m/s)")

        # 2. Búsqueda Binaria del ángulo exacto (Para lograr Exactitud)
        ang_min = 0.0
        ang_max = 800.0  # Límite de tiro tenso/bajo
        
        intentos = 0
        while intentos < 50:
            ang_medio = (ang_min + ang_max) / 2.0
            dist_simulada, tf, h_max = self.simular_vuelo(v0_optima, ang_medio)
            
            # Evaluar precisión requerida
            if abs(dist_simulada - distancia_objetivo) <= tolerancia:
                return {
                    "carga": carga_optima,
                    "v0_empleada": v0_optima,
                    "qe_mils": round(ang_medio, 1),
                    "tf_segundos": round(tf, 2),
                    "altura_maxima_m": round(h_max, 1),
                    "error_residual_m": round(dist_simulada - distancia_objetivo, 2),
                    "algoritmo": "Integración Numérica (Euler Δt=0.005)"
                }
                
            if dist_simulada < distancia_objetivo:
                ang_min = ang_medio
            else:
                ang_max = ang_medio
                
            intentos += 1
            
        return {"error": "No se pudo converger en una solución exacta."}

import math
import os

class SimuladorBalisticoAvanzado:
    def __init__(self):
        # Constantes Físicas
        self.g = 9.80665  # Gravedad m/s^2
        self.rho_0 = 1.225  # Densidad del aire estándar al nivel del mar (kg/m^3)
        self.h_escala = 8500.0  # Altura de escala para el decaimiento exponencial (metros)
        
        # Datos técnicos Obús 105mm (Proyectil HE M1)
        self.masa = 14.97  # kg
        self.calibre = 0.105  # metros
        self.area = math.pi * (self.calibre / 2) ** 2
        self.cd = 0.25  # Coeficiente de arrastre
        
        self.velocidades_carga = {
            "Carga 1": 200.0,
            "Carga 2": 250.0,
            "Carga 3": 300.0
        }

    def simular_vuelo(self, v0: float, theta_mils: float, v_viento: float, dt: float = 0.001) -> tuple[float, float, float]:
        """
        Calcula la trayectoria exacta aplicando:
        - Densidad del aire variable segun la altitud.
        - Arrastre aerodinamico basado en velocidad relativa al viento.
        """
        # 6400 mils = 2*pi radianes
        theta_rad = (theta_mils * 2 * math.pi) / 6400.0
        
        x, y = 0.0, 0.0
        vx = v0 * math.cos(theta_rad)
        vy = v0 * math.sin(theta_rad)
        
        t = 0.0
        y_max = 0.0
        
        while y >= 0:
            # 1. Variacion de densidad del aire segun la altitud (Troposfera simplificada)
            rho = self.rho_0 * math.exp(-y / self.h_escala)
            factor_drag = (rho * self.cd * self.area) / (2 * self.masa)
            
            # 2. Velocidad del proyectil relativa al aire (Viento de cola > 0, de frente < 0)
            v_rel_x = vx - v_viento
            v_rel_y = vy
            v_rel = math.hypot(v_rel_x, v_rel_y)
            
            # 3. Fuerzas y aceleraciones resultantes
            ax = -factor_drag * v_rel * v_rel_x
            ay = -self.g - (factor_drag * v_rel * v_rel_y)
            
            # 4. Integracion numerica de Euler
            x += vx * dt + 0.5 * ax * (dt**2)
            y += vy * dt + 0.5 * ay * (dt**2)
            
            vx += ax * dt
            vy += ay * dt
            
            t += dt
            if y > y_max:
                y_max = y
                
        return x, t, y_max

    def buscar_solucion(self, distancia_objetivo: float, v_viento: float) -> dict:
        """
        Encuentra la carga y la elevacion necesarias por aproximaciones binarias.
        """
        carga_optima = None
        v0_optima = 0.0
        
        # Seleccion de la carga minima que cubra la distancia
        for carga, v0 in self.velocidades_carga.items():
            dist_max, _, _ = self.simular_vuelo(v0, 800.0, v_viento)
            if dist_max >= distancia_objetivo:
                carga_optima = carga
                v0_optima = v0
                break
                
        if not carga_optima:
            return {"error": f"Distancia {distancia_objetivo}m fuera de alcance."}
            
        # Busqueda binaria del angulo de tiro tenso
        ang_min, ang_max = 0.0, 800.0
        for _ in range(50):
            ang_medio = (ang_min + ang_max) / 2.0
            dist_simulada, tf, h_max = self.simular_vuelo(v0_optima, ang_medio, v_viento)
            
            if abs(dist_simulada - distancia_objetivo) <= 0.5:
                return {
                    "carga": carga_optima,
                    "qe_mils": round(ang_medio, 1),
                    "tf_s": round(tf, 2),
                    "h_max_m": round(h_max, 1),
                    "viento_m_s": v_viento,
                    "distancia_objetivo": distancia_objetivo
                }
            
            if dist_simulada < distancia_objetivo:
                ang_min = ang_medio
            else:
                ang_max = ang_medio
                
        return {"error": "No se pudo converger en una solucion precisa."}
