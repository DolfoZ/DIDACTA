# 🏗️ Arquitectura de Integración: API REST + Módulo DREV

A continuación presento la adaptación completa del **Motor de Conocimiento Balístico ARES** para operar como:
1. **Backend REST (FastAPI)**: Expone cálculo de soluciones de tiro, generación de tablas FT y base de datos doctrinal.
2. **Módulo Frontend DREV**: Panel táctico integrado en la interfaz existente que consume la API, visualiza resultados en formato militar y mantiene auditoría.

---

## 🔹 1. Backend: `api_server.py` (FastAPI + Motor ARES)

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
ARES BALLISTIC REST API - Backend para Integración DREV/ARES OS
Compatible con OpenAPI 3.0, validación Pydantic, auditoría STANAG 4355
"""

import os
import sys
from typing import List, Optional, Dict, Any
from fastapi import FastAPI, HTTPException, BackgroundTasks
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field, validator
from contextlib import asynccontextmanager

# Importar el motor de conocimiento (ajustar ruta según despliegue)
sys.path.append(os.path.dirname(__file__))
from motor_conocimiento_ares import SistemaDemostracionAlcance3, FisicaAlcance1

# ============================================================================
# CONFIGURACIÓN Y LIFECYCLE
# ============================================================================
@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.engine = SistemaDemostracionAlcance3()
    print("✅ Motor Balístico ARES inicializado. Memoria cargada.")
    yield
    print("🛑 Motor Balístico ARES detenido.")

app = FastAPI(
    title="ARES Ballistic Core API",
    version="2.1.0",
    description="Motor de cálculo balístico doctrinal para sistemas DREV/ARES OS",
    lifespan=lifespan
)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # Restrictir en producción
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# ============================================================================
# MODELOS DE DATOS (Pydantic)
# ============================================================================
class FireSolutionRequest(BaseModel):
    projectile_id: str = Field(..., description="ID del proyectil (ej: 155_HE_M107)")
    charge_id: str = Field(..., description="ID de la carga (ej: 155_WB_M4A2)")
    range_m: float = Field(..., gt=0, description="Alcance objetivo en metros")
    wind_x: float = Field(0.0, description="Viento longitudinal (m/s)")
    wind_z: float = Field(0.0, description="Viento transversal (m/s)")
    pressure_hpa: float = Field(1013.25, description="Presión atmosférica")
    temperature_c: float = Field(15.0, description="Temperatura ambiente")
    latitude: float = Field(14.08, description="Latitud operacional (Honduras)")

    @validator("projectile_id", "charge_id")
    def validate_ids(cls, v):
        return v.upper().replace(" ", "_")

class FireSolutionResponse(BaseModel):
    success: bool
    data: Optional[Dict[str, Any]] = None
    audit: Dict[str, Any]
    error: Optional[str] = None

class FiringTableRequest(BaseModel):
    projectile_id: str
    charge_id: str
    step_km: float = Field(1.0, ge=0.5, le=5.0)

class AmmoDBResponse(BaseModel):
    projectiles: Dict[str, Any]
    charges: Dict[str, Any]

# ============================================================================
# ENDPOINTS REST
# ============================================================================
@app.get("/health")
async def health_check():
    return {"status": "operational", "engine": "loaded", "version": "2.1.0"}

@app.get("/api/v1/ammo-db", response_model=AmmoDBResponse)
async def get_ammo_database():
    engine: SistemaDemostracionAlcance3 = app.state.engine
    return {
        "projectiles": {pid: p.__dict__ for pid, p in engine.memoria.proyectiles.items()},
        "charges": {cid: c.__dict__ for cid, c in engine.memoria.cargas.items()}
    }

@app.post("/api/v1/fire-solution", response_model=FireSolutionResponse)
async def calculate_fire_solution(req: FireSolutionRequest):
    engine: SistemaDemostracionAlcance3 = app.state.engine
    try:
        # Validación doctrinal rápida
        if req.projectile_id not in engine.memoria.proyectiles:
            raise ValueError(f"Proyectil {req.projectile_id} no encontrado en memoria")
        if req.charge_id not in engine.memoria.cargas:
            raise ValueError(f"Carga {req.charge_id} no encontrada en memoria")
            
        proy = engine.memoria.proyectiles[req.projectile_id]
        carga = engine.memoria.cargas[req.charge_id]
        if req.charge_id not in proy.compatible_cargas:
            raise ValueError(f"Combinación {req.projectile_id} + {req.charge_id} NO COMPATIBLE doctrinalmente")

        # Ejecutar motor
        resultado = engine.demostrar_disparo(req.projectile_id, req.charge_id, req.range_m)
        
        # Ajustar por ambiente (simplificado para API)
        resultado["ambiente"] = {
            "wind_x": req.wind_x, "wind_z": req.wind_z,
            "pressure_hpa": req.pressure_hpa, "temperature_c": req.temperature_c
        }
        
        return FireSolutionResponse(success=True, data=resultado, audit=resultado["auditoria"])
    except ValueError as e:
        return FireSolutionResponse(success=False, audit={"estado": "RECHAZADO"}, error=str(e))
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"Error de simulación: {str(e)}")

@app.post("/api/v1/generate-table", response_model=List[Dict])
async def generate_firing_table(req: FiringTableRequest):
    engine: SistemaDemostracionAlcance3 = app.state.engine
    carga = engine.memoria.cargas.get(req.charge_id)
    if not carga:
        raise HTTPException(404, "Carga no encontrada")
        
    rangos = [int(r) for r in range(1000, int(carga.alcance_max_km * 1000), int(req.step_km * 1000))]
    return engine.sim.generar_tabla_ft(req.projectile_id, req.charge_id, rangos)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run("api_server:app", host="0.0.0.0", port=8000, reload=False)
```

async function generateTable() {

    alert('Error generando tabla FT');

}

## 🔹 3. Despliegue y Conexión en ARES OS

### `docker-compose.yml` (Recomendado para ARES OS)
```yaml
version: "3.8"
services:
  ares-ballistic-api:
    build: .
    ports: ["8000:8000"]
    environment:
      - PYTHONUNBUFFERED=1
    volumes:
      - ./motor_conocimiento_ares.py:/app/motor_conocimiento_ares.py
      - ./api_server.py:/app/api_server.py
    restart: unless-stopped
    networks: [ares-net]

  ares-drev-web:
    image: nginx:alpine
    ports: ["80:80"]
    volumes:
      - ./drev_interface:/usr/share/nginx/html
    depends_on: [ares-ballistic-api]
    networks: [ares-net]

networks:
  ares-net:
    driver: bridge
```

### `Dockerfile` (Backend)
```dockerfile
FROM python:3.11-slim
WORKDIR /app
RUN pip install fastapi uvicorn pydantic
COPY . .
EXPOSE 8000
CMD ["uvicorn", "api_server:app", "--host", "0.0.0.0", "--port", "8000"]
```

## ✅ Características Operativas Integradas

| Componente | Función Doctrinal | Validación |
|------------|-------------------|------------|
| **FastAPI `/fire-solution`** | Cálculo QE/TOF/Drift vía RK4 + Bisección | Compatibilidad munición/carga, límites STANAG |
| **FastAPI `/generate-table`** | Tablas FT 7 columnas (ΔQE, ΔDefl_W1) | Rango máx doctrinal, convergencia <0.5 mils |
| **DREV Panel JS** | Consumo táctico, formato mils/m/segundos | Auditoría en pantalla, alertas CRÍTICO/ADVERTENCIA |
| **Memoria Central** | `MotorMemoriaConocimiento` | Trazabilidad FT 155-AM-2 / TM 43-0001-28 |

### 🛡️ Notas de Seguridad para Producción
1. Reemplazar `allow_origins=["*"]` por la IP/domain de ARES OS.
2. Añadir middleware JWT en FastAPI para roles `FO`, `CP`, `BATERIA`.
3. Rate-limiting en endpoints de cálculo para evitar DoS en simulación numérica.
4. Logs estructurados (JSON) enviados a `syslog` o Elasticsearch para auditoría táctica.
