## Description

This cartridge, which is used to distribute leaflets, is exactly the same as BE [smoke cartridge M84](cartridge_-105mm-smoke-h_-c__-.html) except that it is issued with empty canisters. Printed leaflets are placed in the canisters by field personnel.
